# Boğaziçi Üniversitesi Zeybek Ekibi

Ekip resmi web sitesinin kaynak kodları.

🌐 **Site:** https://bogazicizeybek.netlify.app
✏️  **İçerik Paneli:** https://bogazicizeybek.netlify.app/admin

## Klasör Yapısı

- `index.html` — Sitenin ana sayfası
- `admin/` — İçerik yönetim paneli (CMS)
- `content/` — Site içerikleri (ayarlar, etkinlikler, çalışmalar)
- `images/` — Sabit görseller (logo) + CMS yüklemeleri
- `build.js` — Deploy sırasında çalışan derleme scripti

## İçerik Nasıl Düzenlenir

1. https://bogazicizeybek.netlify.app/admin adresine gidin
2. E-posta ile giriş yapın (ilk seferde davet alacaksınız)
3. Sol menüden "Etkinlikler", "Çalışmalarımız" veya "Site Ayarları"nı seçin
4. Düzenleyin ve "Publish" butonuna basın
5. Site 1-2 dakika içinde otomatik güncellenir
